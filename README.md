## Stack
React, TypeScript, Vite, Three.js / React Three Fiber, GSAP, WebGL.

## Run locally
```bash
npm ci
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deployment
Import this repository into Vercel and use the default Vite build settings:
- Build command: `npm run build`
- Output directory: `dist`
